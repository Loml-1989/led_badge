# LED Badge Project
Welcome to the LED Badge project! This is an open-source, wearable LED badge build using ESP32 as microcontroller and ws2812b LEDs.
This repo contains the full kicad schematic and PCB files.
## Features
- **Microcontroller**: Powered by the smol Seeed Studio XIAO ESP32-C5. It provides wifi and bluetooth capabilities, allowing for wireless animation control, and web interfaces.
- **Display**: A matrix of ws2812b (2020) LEDs.
- **User Input**: Integrated tactile push buttons for physical interactions such as mode switching, and brightness adjustments.
- **Form Factor**: Designed as a minimal 2 layer PCB for wearing as badge.
## Hardware Specifications
- **MCU**: XIAO ESP32-C5 SMD
- **LEDs**: ws2812b-2020
- **Passives**: Standard 0805 imperial (2012 metric) SMD resistors and capacitors
- **Switches**: 6mm tactile push buttons
